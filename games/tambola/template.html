Housie

The classic Indian lottery game — Housie / Bingo — playable with up to 10 friends, right in your browser. No app install needed.

  • 1–10 players with custom names
  • Auto-generated valid Tambola tickets
  • Manual or auto number drawing
  • Adjustable draw speed
  • Prize tracking: Early Five, Top/Mid/Bot Line, Full House
  • Voice announcement via Web Speech API
  • Synthesized ball-drop sound effects
  • Win celebrations with confetti

Features

What's Included

🎟️
Valid Ticket Generation
Every ticket is a proper 3×9 Tambola ticket with exactly 5 numbers per row in the correct column ranges.
🔢
90-Ball Board
Full 1–90 number board. Drawn numbers are highlighted in real time with animated indicators.
🏆
5 Prize Types
Track Early Five, Top Line, Middle Line, Bottom Line, and Full House prizes automatically.
🔊
Voice & Sound
Each drawn number is announced via browser Speech Synthesis, with synthesized ball-drop sounds.
⏱️
Auto Draw Mode
Enable auto-draw and pick a speed from slow (4s) to fast (0.7s) for hands-free games.
🎉
Win Celebrations
Colourful confetti and a win overlay celebrate each prize, queuing multiple winners gracefully.
