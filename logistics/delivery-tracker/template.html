Getting Started
1
Prerequisites
Node.js 20+, PostgreSQL 15, Redis 7, Git
2
Clone & Install
# Clone the repository
git clone https://github.com/ikppramesh/everything.git
cd everything/logistics/delivery-tracker
npm install
3
Configure Environment
cp .env.example .env
# Edit .env with your values:
DATABASE_URL=postgresql://user:pass@localhost:5432/deliverit
REDIS_URL=redis://localhost:6379
JWT_SECRET=change-me-in-production
TWILIO_API_KEY=
SENDGRID_API_KEY=
AWS_S3_API_KEY=
RAZORPAY_API_KEY=
4
Run Development Server
npm run dev
# App runs at http://localhost:3000
# Admin panel at http://localhost:3000/admin
5
Deploy to Production
npm run build
# Deploy with Docker:
docker compose up -d
# Or deploy to Vercel / Railway / Render
