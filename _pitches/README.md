## How to add a new pitch

Ask the Orchestrator: *"Prepare a pitch for \<Company Name\> for the \<solution name\> solution"*

The Pitch Agent will:
1. Research the company
2. Customise the solution's PITCH.md
3. Save the output here as `_pitches/<company-slug>/PITCH-<CompanyName>.md`
4. Upload to Google Drive
5. Notify #sales on Slack
6. Update this index
