How Blockchain Security Works

The five principles this explorer teaches interactively.

1

Every block contains the hash of the previous block

This cryptographic link means every block's identity depends on all the blocks before it, forming a chain of trust.

2

Changing any data changes that block's hash

SHA-256 produces a completely different output even for a single-character change — the avalanche effect makes cheating detectable immediately.

3

The next block's "prevHash" no longer matches

As soon as one block's hash changes, every subsequent block's previous-hash pointer becomes invalid, visually shown as a red cascade.

4

You must re-mine that block AND every block after it

Proof-of-work means finding a nonce that makes the hash start with N zeros. With difficulty 4, that can take tens of thousands of attempts per block.

5

On Bitcoin, this means redoing years of computational work

The honest chain keeps growing while an attacker tries to catch up. This makes successful 51% attacks astronomically expensive on large chains.
